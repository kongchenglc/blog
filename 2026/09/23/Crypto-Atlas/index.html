Crypto Fundamentals

Hash Functions

A hash function converts arbitrary data into a fixed-size value. It is deterministic and designed to be effectively irreversible.

Changing the input produces a very different hash.

Public / Private Keys

A private key is secret and is used to sign transactions. A public key can be derived from the private key and can be shared publicly.

The private key must never be exposed.

Digital Signatures

A digital signature proves that a message or transaction was authorized by the holder of a private key without revealing the private key itself.

Addresses

An address is a public identifier used to send and receive assets.

An address can be shared publicly; the private key cannot.

Wallets

A wallet manages keys and signs transactions. It does not literally store cryptocurrency; assets are recorded on the blockchain.

Seed Phrases

A seed phrase is a human-readable backup used to derive wallet private keys.

Anyone with the seed phrase can usually control the wallet, so it must be kept secret.

Transactions

A transaction is a signed instruction submitted to the blockchain, such as transferring tokens or calling a smart contract.
